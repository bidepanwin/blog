## 外部超链接统一新窗口打开

- 需求：站点里仍有部分外链在当前窗口跳转（Markdown 正文、`set:html` 报告 HTML、少量组件、客户端动态插入的链接）。
- 方案（双层，共用同一判定）：
  - `src/utils/external-link.mjs`：`siteHosts()` / `isExternalHref()` / `mergeExternalRel()`。只有 http(s) 绝对或协议相对地址、且 host 不属于 `siteConfig.site` 或 `location.host` 才算外部；保留已有 `rel` 语义。
  - 构建期 `src/plugins/rehype-external-links.mjs`：遍历 HAST 给 `a[href]` 补 `target="_blank"` + `rel`，跳过已有非新窗口 target、`download`、站内与非网页协议。注册到 `siteRehypePlugins`，位于 `rehypeResponsiveTables` 之后、`rehypeBasePath` 之前（base path 保持链末端）。
  - 运行时 `src/utils/external-links-runtime.mjs`：在 `src/layouts/Layout.astro` 挂载；首屏全量扫描 + `swup:content:replace` / `page:view` + MutationObserver（childList/subtree + href 属性变化）；对已有 `target="_blank"` 的链接也补齐安全 rel。
- Swup 无需改配置：`swup@4.8.2` 的 `triggerWillOpenNewWindow()` 会跳过 `[target="_blank"]` 与 `[download]`。
- 同步改动：`docs/markdown-plugin-order.md` Rehype 阶段表新增两行 + §3.2 依赖边；`src/components/organisms/GardenHeader.astro` 桌面/移动两处 `external` 导航补 `target`/`rel`；新增 `tests/plugins/markdown/external-links.test.mjs`（6 例）。
