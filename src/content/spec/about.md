# 你好，我是 bidepan

欢迎来到 **PAN LOG**，我的个人博客。你也可以在 GitHub 上通过 **bidepanwin** 找到我。

我的 GitHub 简介只有一句话：**do and win**。对我来说，动手是理解问题的一种方式：把一个念头做成可以打开的网页、可以操作的工具，再从真实的使用中继续修改。这个小站也是如此，从外观、交互到内容维护，我希望它逐渐长成自己的样子。

**独立思考，明辨是非。** 这是我给 PAN LOG 写下的提醒。我想在这里留下做事的过程、判断的依据，以及那些暂时没有答案的问题。

## 我在探索什么

我关注网页交互、可视化与 AI 应用，也喜欢尝试技术与日常主题之间的连接。下面这些公开项目，可以作为认识我的几个入口：

- **[Chaos Atlas](https://github.com/bidepanwin/chaos-atlas)**：把混沌系统、流场与粒子生命做成交互场景，探索数学、运动与生成艺术的视觉表达。
- **[廿四 · 节气之轮](https://github.com/bidepanwin/solar-terms-wheel)**：用原生 HTML、CSS、JavaScript 和 Canvas，把二十四节气呈现为可以拖动的罗盘，让颜色与天象粒子随节气变化。
- **[城市周末旅行指南](https://github.com/bidepanwin/citytravel)**：围绕城市周边出行整理目的地、筛选、行程与地图，尝试把信息组织成便于浏览的页面。
- **[Financial-RAG](https://github.com/bidepanwin/Financial-RAG)**：探索金融资料与长文档的知识库管理、检索和问答，关心如何让回答关联到可查阅的来源。

这些项目的方向各不相同，但都有一个共同的起点：遇到感兴趣的问题，先做出一个可以体验、可以验证的版本。后续的改进、取舍和踩坑，也值得被记录下来。

## 这里会记录什么

- **项目与实践**：从想法到实现，记录交互设计、工具使用、部署和维护中的具体问题。
- **AI 与思考**：关注 RAG、AI 工具以及 AGI 时代的变化，整理自己的理解，也保留继续修正的空间。
- **灵感与随记**：收藏值得回看的发现，让零散的想法有一个可以继续生长的地方。

站内仍保留部分用于验证功能的示例文章、随记与列表数据，它们会逐步被真实记录替换。示例中的经历不代表我的个人履历。

## 关于 PAN LOG

这个小站基于 [Astro](https://astro.build/) 与开源主题 [Shirone](https://github.com/LyraVoid/Shirone) 构建，内容通过 Markdown 和本地文件维护，使用 Git 管理版本，发布到 GitHub Pages。它是我的写作空间，也是一个持续打磨的个人项目。

如果你对这些尝试感兴趣，欢迎到 [我的 GitHub](https://github.com/bidepanwin) 看看。也可以通过 [RSS 订阅](../rss.xml) 关注更新，或从 [文章归档](../archive/) 随意翻翻。
