# 你好，我是 Lin

这里是 **LIN'S LOG**，一处记录技术、阅读和生活的个人空间。站名与个人介绍目前是可替换的示例。

我喜欢把复杂的问题拆解成容易理解的小步骤，也喜欢在忙碌之外，读几页书、走一段路。这个博客用来收集值得停留的瞬间：做过的项目、读到的句子、没想明白的问题，以及日常里细小的发现。

## 这里写什么

- **技术**：前端开发、个人项目和工具实践，记录过程，也记录走过的弯路。
- **生活**：徒步、散步与城市里的日常，给忙碌留一点呼吸的空间。
- **阅读**：阅读笔记与由书延伸出的思考，用自己的话整理理解。

## 关于这个小站

网站基于 Astro 与开源主题 [Shirone](https://github.com/LyraVoid/Shirone) 构建，沿用参考仓库的大幅横幅、双侧栏、文章卡片与多栏目结构。内容通过 Markdown 和本地数据文件维护，首页、归档、分类、标签和 RSS 会随文章更新。

比起持续输出完整的答案，我更在意诚实地记录探索的过程。文章会随着新的经验继续修改，也欢迎你带着不同的角度来阅读。

## 保持联系

你可以通过 [RSS 订阅](/rss.xml) 获取新文章，或者去 [归档](/archive/) 随意翻翻。小站还在生长，感谢你路过。

> 当前文章与随记为搭建阶段的示例内容，后续会逐步替换为自己的记录。
