让新的内容上线

保存只更新这台电脑上的文件。完成下面的检查、提交与部署后，线上博客才会更新。

  1. 先保存到本地在编辑页点击“保存”。准备公开的文章需先取消“草稿”并保存。
  2. 预览并运行检查检查本地站点和右侧变更清单，再点击下方“运行检查”。
  3. 提交并发布填写更新说明，点击“提交并发布”并确认；等待 GitHub Pages 部署成功后再查看线上博客。

不会提交其他来源的本地改动。公开仓库中的 Markdown 源文件和图片也会随提交公开。发布需要此电脑已登录 GitHub，并拥有仓库推送权限。
